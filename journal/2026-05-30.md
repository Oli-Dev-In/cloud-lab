## Learned
- ACLs extend standard permissions — allow per-user and per-group permissions beyond owner/group/others
- getfacl: displays ACL entries of a file — always check before and after modifying
- setfacl -m u:username:r-- : grant read-only to specific user
- setfacl -m u:username:--- : remove all permissions from specific user
- sed -i 's/old/new/g': replace all occurrences directly in file — no editor needed
- sed without -i: preview changes without modifying the file
- Files in /root require sudo for both sed and grep
- scp user@host:/path: copy files between servers over SSH
- 100% in scp output confirms successful transfer
